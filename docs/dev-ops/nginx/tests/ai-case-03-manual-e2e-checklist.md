# ai-case-03 手工 E2E 回归清单

## 目标
验证登录首页与业务工作台闭环是否满足 AC-02、AC-03、AC-05、AC-06、AC-08。

## 前置条件
- Nginx 已托管 `docs/dev-ops/nginx/html` 静态页面。
- 后端 `/api/v1/rag/query_rag_tag_list` 与 `generate_stream_rag` 接口可访问。
- 浏览器开发者工具可查看网络请求与控制台日志。

## 用例

### TC-LOGIN-002: 未登录门禁
1. 打开 `index.html`。
2. 不登录，尝试通过控制台触发发送按钮点击（或 UI 直接尝试业务操作）。
3. 观察登录区状态提示。

预期结果：提示“请先登录”，业务能力不可用且不应发起聊天请求。

### TC-LOGIN-003: 登录后进入工作台
1. 输入有效账号与密码。
2. 提交登录。

预期结果：登录区隐藏，工作台展示，会话管理/模型选择/知识库选择/消息区可见。

### TC-STREAM-005: 流式增量与结束停流
1. 登录后选择通道、模型、知识库标签。
2. 发送一条问题。
3. 观察回答是否逐步追加。
4. 确认流式结束后“停止”按钮恢复禁用，“发送”按钮恢复可用。

预期结果：消息按分片增量渲染，收到结束标记后停止。

### TC-SESSION-006: 刷新恢复
1. 在同一会话发送 2~3 条对话。
2. 刷新页面并重新登录（如果 sessionStorage 过期则需重登）。

预期结果：会话列表、当前会话与历史消息恢复。

### TC-NAV-008: 上传入口跳转
1. 登录后点击“上传入口 -> 上传知识库”。
2. 返回后再点击“上传入口 -> 上传代码库”。

预期结果：分别跳转到 `rag-upload.html` 与 `code-upload.html`。
